HearthLedger is a working household budget site: track income and spending by category, set monthly category budgets with progress and over-budget warnings, follow savings goals, and read computed insights — all offline, in the browser, with data kept in localStorage.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts   # build the hand-in dossier
python3 -m http.server 8080 --directory app   # then open http://localhost:8080 to use the site
```
